# Problems – Codeforces (Pattern Printing)

This repository contains pattern printing problems from Codeforces.

---

## A. 2-Stars

**Time Limit:** 1 second
**Memory Limit:** 256 MB

You are given a positive integer `n`.

Print a pattern consisting of `n` rows, where each row contains exactly two stars (`**`).

### Input

```
5
```

### Output

```
**
**
**
**
**
```
