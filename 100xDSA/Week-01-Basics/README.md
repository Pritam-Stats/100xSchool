# Problems – Week 1 (CodeForces)

This repository contains a collection of beginner-friendly problems focused on basic programming concepts such as input/output, conditionals, loops, arithmetic operations, and simple logic building.

---

## A. Hello World

**Time Limit:** 1 second
**Memory Limit:** 256 MB

**Problem:**
Print the string `Hello World`.

**Input:**
No input.

**Output:**

```
Hello World
```
