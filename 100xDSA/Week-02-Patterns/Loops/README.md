# Problems – Codeforces (Loops)

This repository contains loop-based beginner problems from Codeforces.

---

## A. Print 1 to N

**Time Limit:** 1 second
**Memory Limit:** 256 MB

You are given a positive integer `N`.
Print the integers from `1` to `N` (inclusive), each on a separate line.

### Input

A single integer `N`.

### Output

Print `N` lines. On the `i`-th line, output the integer `i`.

### Example

**Input**

```
5
```

**Output**

```
1
2
3
4
5
```

## B. Print N to 1

**Time Limit:** 1 second
**Memory Limit:** 256 MB

You are given an integer `N`.
Print all integers from `N` to `1` in decreasing order.

### Input

A single integer `N`.

### Output

Print integers from `N` to `1`, separated by spaces.

### Example

**Input**

```
5
```

**Output**

```
5 4 3 2 1
```

## C. Print All Even Numbers from 1 to N

**Time Limit:** 1 second
**Memory Limit:** 256 MB

You are given an integer `N`.
Print all even numbers between `1` and `N` (inclusive) in increasing order.

### Input

A single integer `N`.

### Output

Print all even numbers separated by spaces.

### Example

**Input**


## G. Count Numbers

**Time Limit:** 1 second
**Memory Limit:** 256 MB

You are given an integer `N` followed by `N` integers.
Count how many of the numbers are:

* Positive
* Negative
* Even
* Odd

Zero is neither positive nor negative.
Zero is considered even.

### Input

```
N
A1 A2 ... AN
```

### Output

Print four integers:

1. Number of positive integers
2. Number of negative integers
3. Number of even integers
4. Number of odd integers
